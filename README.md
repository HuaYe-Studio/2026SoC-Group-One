 憨蛋学步

一款由 **蒸蒸日上** 开发的 2D 类银河城（Metroidvania）游戏。玩家扮演一只史莱姆（憨蛋），通过**吞噬**地图上的动物获得它们的形态与能力，不断解锁新能力探索更广阔的湿地世界。

> 开发引擎：Unity 2022.3 LTS · 渲染管线：URP 2D

## 玩法核心

- **吞噬**：靠近动物按下交互键，将动物吞入体内
- **变身**：按 Tab 打开形态轮盘，在已解锁的形态间自由切换
- **探索**：每种形态拥有独特能力，用于跨越不同地形障碍，越吃越强、越走越远

## 形态系统

| 形态 | 能力 | 解锁方式 |
|------|------|----------|
| 史莱姆 Slime | 贴墙攀爬、喷火（需吞噬火晶石解锁火元素） | 初始形态 |
| 青蛙 Frog | 蓄力跳跃、踩墙跳 | 吞噬青蛙 |
| 气泡鱼 BubbleFish | 水下漂浮、下潜 | 吞噬气泡鱼 |
| 绵羊 Sheep | 蓄力冲锋滑行 | 吞噬绵羊 |

## 操作说明

| 操作 | 键盘 | 手柄（Xbox） |
|------|------|--------------|
| 移动 | A / D | 左摇杆 |
| 攀爬 | W / S | 右摇杆 |
| 跳跃 | 空格 | B |
| 吞噬 | 空格 | Y |
| 形态轮盘 | Tab | 方向键右 |
| 喷火（史莱姆） | J | — |
| 吐出持有物 | F | X |
| 能力 1 / 能力 2 | 鼠标左键 / 鼠标右键 | A / 方向键左 |
| 菜单 | Esc | 左摇杆按下 |

## 世界与内容

- **区域**：湿地 WetLand（主场景）、森林 Zone1_Forest、洞穴 Zone2_Cave
- **动物**：青蛙、气泡鱼、绵羊、蜘蛛（AI 行为树驱动）
- **Boss**：蜜蜂（A* 寻路）
- **地图交互物**：火焰喷射器、尖刺、弹簧床、记忆碎片、移动平台、滑动门等

## 技术栈

- Unity **2022.3.62f3c1** LTS
- **URP 2D** 渲染管线
- Unity **Input System**（新输入系统）
- **Cinemachine** 摄像机系统
- **TextMeshPro** UI 文本
- **DOTween** 动画库（插件形式引入）
- **Git LFS** 管理二进制资源

## 开发与构建

1. 使用 Unity 2022.3.62f3c1 打开项目（推荐 JetBrains Rider）
2. 首次打开等待生成 `.csproj` / `.sln`（已 gitignore）
3. 打包场景：`Scene_MainMenu`（主菜单）、`WetLand_Main`（游戏主关卡）

## 项目结构

```
Assets/
├── Forms/        形态系统（史莱姆、青蛙、气泡鱼、绵羊）
├── Mechanics/    吞噬机制（DevourHandler 等）
├── Scripts/      核心脚本（输入、能力、摄像机、UI、存档）
├── AI/           动物 AI（行为树、寻路）
├── Maps/         关卡地图与交互物
└── Audio/        音频
```
